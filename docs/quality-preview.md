# 数据质量预览

预览是独立、只读的消费功能，复用 Event v1、Consumer 和 Projection。不会调用交易所，不会回补数据，也不会修改原始行情或发出订单。

## 使用

```bash
uv sync --frozen --extra preview
uv run market-service preview --db data/btc.sqlite --output data/quality-001.html --png data/quality-001.png --report data/quality-001.json
```

HTML 包含 Plotly 源码，可离线悬停、缩放、切换图例和导出图片；PNG 使用 Matplotlib Agg，不启动浏览器。两个渲染器读取同一份已校验网格。HTML / PNG / JSON 均要求使用新路径，禁止与源库及 SQLite sidecar 重叠。JSON 是预览口径、计数与哈希摘要。

可以在活动采集库上执行：一次只读 WAL 事务固定原始输入与事件水位，两遍重放不会跨到新提交。长事务会阻止一部分 WAL 空间回收，繁忙或较大的日志可先创建一致性备份，再对备份预览。

默认展示最后20000个事件，最多100000个。事件序号决定窗口，窗口长度会随成交活跃度变化，不是固定20分钟：

```bash
uv run market-service preview --db data/btc.sqlite --output data/quality-002.html --max-events 5000 --time-bin-ms 100 --max-time-bins 600 --price-bins 120 --band-bps 20 --stale-seconds 10
```

默认以窗口盘口中位价格为中心、两侧各20bp显示价格带。价格格对齐整数 tick；`--price-bins` 决定格数。时间格默认100ms；窗口太长时自动放大到100ms的整数倍，最多600列。实际格宽写在页面和 JSON 中；这种显示聚合不改变原始日志频率。

## 如何读图

- **主热力图**：每格表示有效覆盖时间内该价格格的可见挂单量，单位为基础币 BTC。按持续时间加权平均，不将每次深度更新累加；颜色为 log(1+数量)，色条刻度和悬停显示实际 BTC。
- **灰色空白**：盘口无效、过期、尚在同步，或价格格超出快照已知边界。只要一个时间格存在未覆盖时段，就不为该格绘制完整深度。有效覆盖内零挂单才画为最低色阶。灰色不能解读为流动性真空。
- **最优买卖报价**：每个完整有效盘口时间格末次已知的报价；断线段不连接旧线。
- **质量条**：分别显示连接、盘口和成交的格内最差状态。LIVE、SYNCING、INVALID、DISCONNECTED 来自原契约；STALE、PARTIAL 仅用于展示，不改 Event v1。× 标记保留同批次内瞬时出现、随后恢复的质量边界。
- **成交量**：主动买与主动卖观察成交量，按格求和、非负堆叠。它是收到的数据，不意味着空白或零成交期间交易所没有发生交易。

盘口新鲜度按最后一条 Snapshot / Delta 的原始接收年龄判断，成交消息不能给旧簿续命。页面默认使用10秒阈值；如采集器配置不同，应传入相同的 `--stale-seconds`。尾部窗口从检查点开始时，会有界向前查找深度接收基准；找不到时保守保留未知状态。

## 校验与限制

预览从窗口前最近的检查点恢复，验证检查点 checksum、身份和盘口哈希，随后用同一个 Consumer 逐事件验证事件链和盘口哈希。所选事件引用的原始输入另行验证 checksum；这是窗口校验，不等于对整库所有原始帧和历史前缀执行了 `verify`。

横轴为规范化时间 UTC。墙钟回退时仅将显示坐标单调化并报告次数；绝不按时间戳重排事件。缺失 ID 数来自窗口中的显式 `trade_id_gap`，不把窗口之前的缺口计入，也不查询事后 repaired 目录。快照覆盖以已知边界保守判断，跨边界的价格格仍是未知。

这是显示观察数据质量的工具，不提供精确 maker 队列、隐藏单、撤改单轨迹或100ms批次内部路径。热力图中低挂单量只能说明有效覆盖范围内所观测到的流动性。

## 2026-10-17 本地验收

使用已有真实样本：1047个事件、759笔观察成交、2次快照、268批深度更新；窗口明确显示10个缺失成交 ID。该样本的已验证盘口时长占比约91.1%，主动重连区间不填旧盘口。最终事件链和盘口哈希与原验收结果相同。

数值测试覆盖时间加权、有效零值与未知的区别、部分缺失遮罩、断线、过期、检查点尾部、瞬时成交缺口、墙钟回退、原始输入 / 检查点损坏和输出路径保护。PNG 已生成并人工检查，使用同一聚合结果；HTML 结构与离线脚本通过自动检查。浏览器本地文件地址策略阻止自动打开 HTML，因此交互和窄屏布局尚未做浏览器实测，不将其写成已通过。

Plotly 和 Matplotlib 作为 `preview` 可选依赖，由 `uv.lock` 锁定；不影响仅运行采集器的安装体积。生成的真实数据预览放在本地 `data/`，不随公开仓库分发。
